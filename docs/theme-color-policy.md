# 初期コミット側のテーマ対応

この実装の基点は `fix/dark-theme-color-consistency` の `99a472b`。
`origin/develop` のコード・依存・テーマ定義は取り込んでいない。

この基点には管理・観測ページが存在しないため、トップページだけを対象とする。
存在しないページやコンポーネントは追加しない。

## 変更内容

- ページ背景・本文・補助文字・リンク・枠・ホバーをテーマトークンに統一する。
- `globals.css` に不足するトークンを追加する。補助文字の zinc、枠の黒白の
  不透明度、ホバー色は、この基点の `page.tsx` にあった値を使う。
- 主ボタンの前景と背景は既存の `foreground` / `background` を参照する。
- 暗色のページ背景は既存の `--background` に揃える。
- ロゴの `dark:invert` は視認性を保つために維持する。

## 検証

この作業ツリーの lockfile に合わせて依存を導入し、ビルド・型チェック・
静的チェックを行う。ブラウザーでライト／ダークの文字・背景・枠と
ボタンのホバーを確認し、スクリーンショットを保存する。

検証結果: Next.js 16.2.7 で本番ビルド、TypeScript、変更ファイルの Biome が成功。
両テーマのブラウザーテストも成功した。補助文のコントラスト比は
ライト 7.72:1、ダーク 7.55:1。主・副リンクのホバーで背景が変わることを確認した。
この基点にはユニットテストの設定がないため、ブラウザーによる動作検証を行った。
