# develop 側のテーマ対応

この実装は `origin/develop` の `035a6c0` を基点にした独立ブランチで行う。
初期コミット側の変更や新しいテーマ定義は取り込まない。

## 変更内容

既存のテーマ定義を使い、検出設定・検出状態・開発用パネルの枠を
`border-border`、プリセット数値と配信状態の補助文字を
`text-muted-foreground` に統一する。配信停止の印は観測点のオフライン表示と
同じ `bg-muted-foreground/40` とする。

観測側の検出エラーは `text-destructive` と `role="alert"` で表す。
トップページも背景・本文・枠・ホバーに既存トークンを使う。
固定表示される開発用パネルには `bg-background` を指定する。

## 固定色を残す理由

| 対象                                                                   | 理由                                                             |
| ---------------------------------------------------------------------- | ---------------------------------------------------------------- |
| `DetectionVideoStage` / `VideoReceiverView` の黒背景・半透明黒と白文字 | 映像表示面と、映像上に重ねる案内として使用する。                 |
| `BroadcastIndicator` の赤                                              | 配信中を示す意味色。エラー色とは区別し、状態は文字でも表示する。 |
| `ObservationPointPicker` の緑                                          | オンラインを示す意味色。オフラインは文字でも表示する。           |
| `SelectionHeader` の sky / amber / violet                              | 種類名を補助するバッジ色。各色にダーク用の配色がある。           |
| `PropertyNotice` / `ObservationPointPicker` の amber                   | 警告色。ダーク用の配色があり、アイコンや文言を併用する。         |
| ロゴの `dark:invert`                                                   | 単色ロゴの視認性を保つ。                                         |

配信・オンライン専用の管理 UI トークンがないため、状態の赤・緑を維持する。
ゲスト専用トークンは流用しない。

## 検証

管理ページは接続と設定同期が完了した状態、観測ページは通常とエラー状態を
ライト・ダークの両方で撮影する。通信部分はテスト用データを使い、実際の
画面構成と設定同期処理を通して確認する。実機との通信確認は含まない。
ユニットテスト、型チェック、本番ビルドと関連 E2E を実行する。

検証結果: Next.js 16.4.0 で本番ビルド、TypeScript、変更ファイルの Biome が成功。
全ユニットテスト 512 件中、初回は 510 件成功し、既存の 2 件が時間切れとなった。
該当 2 ファイルの 9 件を 1 ワーカーで再実行し、すべて成功した。
検出設定・検出開始・接続エッジに関係する既存 E2E 22 件も成功した。

両テーマの管理・観測ページ、観測エラー、トップページとホバーを撮影・目視確認した。
画像はローカルの `test-results/theme-screenshots/` に保存している。
